# animal-cam

## Universal Video Kit
`kit/` — Python + React (Remotion) + GitHub Actions। Actions → **Universal Video Kit** → Run workflow।
লোকালি: `python3 kit/uniquify.py --src video/Day01.mp4 --day 01 --duration 150 --resolution 1080p`
Remotion preview: `cd kit/remotion && npm i && npm run studio` (আগে একবার uniquify.py `--no-render` চালান)।
